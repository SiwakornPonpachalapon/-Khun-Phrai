# ขุนพราย (Khun Phrai)

**ขุนพราย** เป็นโปรเจกต์เกม 3D ที่พัฒนาด้วย Unity โดยมีแนวคิดผสมผสานระหว่าง **Souls-like และ Survival** เน้นการต่อสู้ที่ต้องอาศัยจังหวะ การหลบหลีก การบริหารทรัพยากร และการเอาตัวรอด

โปรเจกต์นี้จัดทำขึ้นเพื่อพัฒนาทักษะด้าน **Unity Game Development และการเขียนโปรแกรมด้วย C#** โดยผมรับผิดชอบหลักในส่วนของการพัฒนาระบบ Gameplay และการนำระบบต่าง ๆ ภายในเกมมาทำงานร่วมกัน

---

## 🎮 เกี่ยวกับเกม

เรื่องราวเกิดขึ้นในช่วงปลายสมัยอยุธยา บ้านเมืองอยู่ในช่วงความไม่สงบ มีทั้งกลุ่มโจร กองกำลังรับจ้าง และเรื่องราวเกี่ยวกับไสยศาสตร์และวิญญาณ

ผู้เล่นรับบทเป็น **“อินทร์”** ชาวบ้านธรรมดาที่ออกจากหมู่บ้านเพื่อหาเสบียงและสมุนไพร แต่เมื่อเดินทางกลับมา กลับพบว่าหมู่บ้านถูกโจมตีและครอบครัวของเขาหายตัวไป

อินทร์จึงออกเดินทางเพื่อตามหาครอบครัว พร้อมกับต้องเอาตัวรอดจากอันตรายระหว่างทาง

---

## 🔄 Game Loop

Gameplay หลักของขุนพรายดำเนินผ่านระบบ Quest โดยผู้เล่นจะรับภารกิจจาก NPC ออกไปทำภารกิจในพื้นที่ต่าง ๆ และกลับมาส่ง Quest เพื่อดำเนินเนื้อเรื่องต่อ

### ลำดับ Gameplay

**เริ่มเกม**  
↓  
**พูดคุยกับ NPC และรับ Quest**  
↓  
**Quest 1 — รวบรวมทรัพยากร**  
เดินทางไป **Map 2** เพื่อรวบรวมไม้ หิน และเหล็กตามจำนวนที่กำหนด  
↓  
กลับ **Map 1** และส่ง Quest ให้ NPC  
↓  
**Quest 2 — จัดเก็บทรัพยากร**  
นำทรัพยากรที่รวบรวมมาไปเก็บไว้ในโกดัง  
↓  
กลับไปส่ง Quest และรับภารกิจถัดไป  
↓  
**Quest 3 — อัปเกรดบ้าน**  
นำทรัพยากรจากโกดังมาใช้ในการอัปเกรดบ้าน  
↓  
กลับไปส่ง Quest ให้ NPC และได้รับ **ดาบ**  
↓  
**Quest 4 — กำจัดศัตรู**  
เดินทางไป **Map 2** และกำจัดศัตรูจำนวน **10 ตัว**  
↓  
กลับ **Map 1** เพื่อส่ง Quest และรับภารกิจสุดท้าย  
↓  
**Final Quest — กำจัด Boss**  
เดินทางไป **Map 3** และต่อสู้กับ Boss  
↓  
**จบเกม**

### 🗺️ พื้นที่ภายในเกม

| Map | หน้าที่ |
|---|---|
| **Map 1** | พื้นที่หลัก, NPC, บ้าน, โกดัง และจุดรับ/ส่ง Quest |
| **Map 2** | พื้นที่รวบรวมทรัพยากรและต่อสู้กับศัตรู |
| **Map 3** | พื้นที่สำหรับการต่อสู้กับ Boss |

## ⚔️ Combat System

ระบบต่อสู้ถูกออกแบบให้เน้นจังหวะในการโจมตีและหลบหลีก โดยผู้เล่นไม่สามารถโจมตีต่อเนื่องได้โดยไม่มีข้อจำกัด

### Melee Combat

- ระบบโจมตีแบบ Combo
- รองรับ Combo ต่อเนื่องสูงสุด 4 ครั้ง
- ตรวจจับศัตรูบริเวณอาวุธด้วย Hit Detection
- การโจมตีแต่ละ Combo มีจังหวะ Animation แตกต่างกัน
- Combo สุดท้ายสามารถทำให้ศัตรูหยุดชะงักได้นานขึ้น
- มี Recovery Time หลังจบ Combo
- สามารถใช้ Dash เพื่อยกเลิกการโจมตีในบางจังหวะได้

### Dash / Dodge

- ผู้เล่นสามารถ Dash เพื่อหลบการโจมตี
- จำกัดระยะเวลาและ Cooldown
- ล็อกทิศทางตัวละครระหว่าง Dash
- ไม่สามารถเดินตามปกติระหว่าง Dash
- มี Visual Effect ระหว่างการเคลื่อนที่

## 📜 Quest & Dialogue System

ระบบ Quest เชื่อมต่อกับระบบ Gameplay ต่าง ๆ ภายในเกม โดยผู้เล่นสามารถรับภารกิจและติดตามความคืบหน้าผ่านการสนทนากับ NPC

ตัวอย่างภารกิจภายในเกม เช่น

- รวบรวมทรัพยากร ไม้ หิน และเหล็ก
- นำทรัพยากรไปเก็บในโกดัง
- อัปเกรดบ้าน
- ปลดล็อกอาวุธ
- กำจัดศัตรูตามจำนวนที่กำหนด

ข้อมูลความคืบหน้าของ Quest สามารถบันทึกและโหลดกลับมาได้

## 🌳 Survival & Resource System

## 🧠 Player State System

ใช้ Enum ในการควบคุมสถานะของ Player เพื่อป้องกัน Action ที่ไม่ควรเกิดพร้อมกัน เช่น

```text
Idle
Walk
Run
Dash
Attack
Mining
Cutting
ReadyToTree
ReadyToStone
ReadyToIron
```

ตัวอย่างเช่น เมื่อ Player อยู่ในสถานะ `Attack` หรือ `Mining` ระบบ Movement จะถูกจำกัดจนกว่า Action นั้นจะเสร็จสิ้น

## 🛠️ เครื่องมือและเทคโนโลยี
