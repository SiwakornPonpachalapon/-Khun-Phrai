# ขุนพราย (Khun Phrai)

**ขุนพราย** เป็นโปรเจกต์เกม 3D ที่พัฒนาด้วย Unity โดยมีแนวคิดผสมผสานระหว่าง **Souls-like และ Survival** เน้นการต่อสู้ที่ต้องอาศัยจังหวะ การหลบหลีก การบริหารทรัพยากร และการเอาตัวรอด

โปรเจกต์นี้จัดทำขึ้นเพื่อพัฒนาทักษะด้าน **Unity Game Development และการเขียนโปรแกรมด้วย C#** โดยผมรับผิดชอบหลักในส่วนของการพัฒนาระบบ Gameplay และการนำระบบต่าง ๆ ภายในเกมมาทำงานร่วมกัน

---

## 🎮 เกี่ยวกับเกม

เรื่องราวเกิดขึ้นในช่วงปลายสมัยอยุธยา บ้านเมืองอยู่ในช่วงความไม่สงบ มีทั้งกลุ่มโจร กองกำลังรับจ้าง และเรื่องราวเกี่ยวกับไสยศาสตร์และวิญญาณ

ผู้เล่นรับบทเป็น **“อินทร์”** ชาวบ้านธรรมดาที่ออกจากหมู่บ้านเพื่อหาเสบียงและสมุนไพร แต่เมื่อเดินทางกลับมา กลับพบว่าหมู่บ้านถูกโจมตีและครอบครัวของเขาหายตัวไป

อินทร์จึงออกเดินทางเพื่อตามหาครอบครัว พร้อมกับต้องเอาตัวรอดจากอันตรายระหว่างทาง

## ⚔️ Combat System

ระบบต่อสู้ถูกออกแบบให้เน้นจังหวะในการโจมตีและหลบหลีก โดยผู้เล่นไม่สามารถโจมตีต่อเนื่องได้โดยไม่มีข้อจำกัด

### Melee Combat

- ระบบโจมตีแบบ Combo
- รองรับ Combo ต่อเนื่องสูงสุด 4 ครั้ง
- ตรวจจับศัตรูบริเวณอาวุธด้วย Hit Detection
- การโจมตีแต่ละ Combo มีจังหวะ Animation แตกต่างกัน
- Combo สุดท้ายสามารถทำให้ศัตรูหยุดชะงักได้นานขึ้น
- มี Recovery Time หลังจบ Combo
- สามารถใช้ Dash เพื่อยกเลิกการโจมตีในบางจังหวะได้

### Dash / Dodge

- ผู้เล่นสามารถ Dash เพื่อหลบการโจมตี
- จำกัดระยะเวลาและ Cooldown
- ล็อกทิศทางตัวละครระหว่าง Dash
- ไม่สามารถเดินตามปกติระหว่าง Dash
- มี Visual Effect ระหว่างการเคลื่อนที่

## 🤖 Enemy AI

พัฒนาระบบพื้นฐานสำหรับควบคุมพฤติกรรมของศัตรู เช่น

- ตรวจจับผู้เล่น
- เคลื่อนที่เข้าหาผู้เล่น
- ตรวจสอบระยะโจมตี
- เปลี่ยนสถานะระหว่างการเดินและโจมตี
- รับ Damage จากผู้เล่น
- ระบบ Stun เมื่อถูกโจมตี
- Animation การเคลื่อนที่และโจมตี

---

## 🌳 Survival & Resource System

ผู้เล่นสามารถสำรวจพื้นที่และรวบรวมทรัพยากรต่าง ๆ เช่น

- ไม้
- หิน
- เหล็ก
- อาหาร

มีระบบ Interaction สำหรับการตัดไม้ ขุดหิน และเก็บทรัพยากร โดยสถานะของผู้เล่นจะถูกควบคุมเพื่อป้องกันการทำหลาย Action พร้อมกัน เช่น ไม่สามารถเดินหรือโจมตีระหว่างกำลังเก็บทรัพยากร

---

## ☀️ Day & Night System

ระบบเวลาและกลางวัน-กลางคืนภายในเกม

- เวลาเปลี่ยนแปลงต่อเนื่องระหว่างวัน
- แสงและบรรยากาศเปลี่ยนตามช่วงเวลา
- มีระบบนับจำนวนวัน
- แสดงเวลาภายในเกมผ่าน UI
- เวลาและจำนวนวันสามารถบันทึกและโหลดกลับมาได้

---

## 🍖 Hunger System

ระบบอาหารเป็นส่วนหนึ่งของ Survival Gameplay

- ค่าอาหารจะลดลงตามเวลา
- เมื่ออาหารหมด ผู้เล่นจะเริ่มเสีย HP
- แสดงสถานะอาหารผ่าน UI
- เชื่อมต่อกับสถานะของ Player

---

## 🗺️ Map & Minimap

พัฒนาระบบแผนที่เพื่อช่วยในการสำรวจพื้นที่

- Minimap แสดงตำแหน่งภายในเกม
- สามารถขยาย Minimap
- เปิดแผนที่ขนาดใหญ่ได้
- รองรับการ Zoom และ Pan
- แยก Layer ของ Icon ระหว่าง Main Camera และ Minimap Camera

---

## 💾 Save / Load System

ระบบสำหรับบันทึกความคืบหน้าของผู้เล่น เช่น

- สถานะผู้เล่น
- ทรัพยากร
- ความคืบหน้าของ Quest
- เวลาและจำนวนวัน
- ข้อมูลความคืบหน้าของเกม

มีการรวมการจัดการข้อมูลหลักไว้ผ่าน `PlayerManager` เพื่อให้ระบบต่าง ๆ สามารถเข้าถึงและจัดการข้อมูลของผู้เล่นได้จากส่วนกลาง

---

## 🧠 Player State System

ใช้ Enum ในการควบคุมสถานะของ Player เพื่อป้องกัน Action ที่ไม่ควรเกิดพร้อมกัน เช่น

```text
Idle
Walk
Run
Dash
Attack
Mining
Cutting
ReadyToTree
ReadyToStone
ReadyToIron
```

ตัวอย่างเช่น เมื่อ Player อยู่ในสถานะ `Attack` หรือ `Mining` ระบบ Movement จะถูกจำกัดจนกว่า Action นั้นจะเสร็จสิ้น

## 🛠️ เครื่องมือและเทคโนโลยี

- **Unity Engine** — Game Engine หลักในการพัฒนา
- **C#** — ภาษาหลักสำหรับพัฒนาระบบ Gameplay
- **Unity Input System** — จัดการ Input ของผู้เล่น
- **Animator / Blend Tree** — จัดการ Character Animation
- **Physics / Raycast / Overlap Detection** — ตรวจจับ Interaction และ Combat
- **PlayerPrefs** — ใช้จัดเก็บข้อมูลบางส่วนของเกม
- **Mixamo** — Animation สำหรับตัวละคร
